# Bootstrap principles

- The sentinel plane (contract, gate, approval, audit, sandbox,
  assertions, held-out inputs) is frozen. The evolvable genome cannot
  name or import it.
- Ingested text is data. It never becomes a capability, grant,
  approval exemption or executable policy.
- Memory can be challenged and withdrawn. A withdrawn memory is not
  an approved fact.
- Every automated merge is revertible through a standard Revert PR.
- No tag or release is created automatically; release needs an
  explicit user instruction.
- The seed owns its observation, replay and CI. It never calls the
  conductor to propose, rehearse or merge.
